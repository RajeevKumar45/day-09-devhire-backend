# DevHire Backend API

A beginner-friendly REST API built using Node.js and Express.

This project is part of my full-stack development learning journey.

---

## 🚀 Features

- Node.js backend
- Express.js server
- REST API
- GET all jobs
- GET a single job
- POST a new job
- JSON request and response
- Request validation
- HTTP status codes
- Route parameters
- Basic error handling
